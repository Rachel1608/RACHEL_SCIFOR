# AI/ML INTERN - META SCIFOR TECHNOLOGIES
•	I worked on “AI Avatar Text Generation” project, for the deployment team that develop application for generating the key entities and summary for to train in prebuilt AI Avatar, the web Interface done using Streamlit by cloning it into github.
•	This task is completely done using Python at Visual Studio, the model is trained using Spacy ‘en_core_wb_sm’.
•	As Text Preprocessing, re module is used for generating clean extracted text.
•	And Named Entity Recognition (NER) function for displaying key entities and lastly generated the summary.
•	Through this project we achieved good performance of the model by producing the Key Entities like Dates, Organisations, Places and Summary for the user.
